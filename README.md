## About

Full-stack developer from Nepal with a **strong focus on the frontend**. My core craft is building fast, accessible and responsive interfaces with **React, Next.js, TypeScript and Tailwind CSS**, from marketplaces and e-commerce stores to admin dashboards and business websites. I also build the backend: **Java, Spring Boot REST APIs, JWT / OAuth2 security, PostgreSQL / MongoDB and Docker**, so I can take a product from Figma design to deployed API.
